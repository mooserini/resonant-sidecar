## Variant: Quiet Context Strip

### Design stance
Keep conversation primary while a compact strip states exactly what Hermes knows about the adjacent page.

### Key choices
- Layout: slim identity bar, title/site context strip, quiet conversation canvas, persistent composer.
- Typography: contemporary system type with restrained PC-terminal cues only in the Hermes mark.
- Color: dark Resonant Mirror earth tones; magenta is reserved for focus and Tom’s greeting.
- Interaction: “Share more…” opens bounded depth/lifetime choices; camera creates a removable one-shot attachment.

### Trade-offs
- Strong at: calm daily use, low cognitive load, and keeping page identity distinct from page-content access.
- Weak at: making detailed context provenance continuously visible after several attachments accumulate.

### Best for
- A mainstream Hermes companion where conversation should remain visually dominant.
