## Variant: Quiet Companion

### Design stance
The conversation stays primary while browser context and tool activity remain visible without becoming a cockpit.

### Key choices
- Layout: single-column conversation with a compact current-tab card.
- Typography: contemporary system sans; no terminal cosplay.
- Color: warm Resonant Mirror earth tones with restrained magenta and green state accents.
- Interaction: expandable tool receipt, agent picker feedback, explicit read-only scope.

### Trade-offs
- Strong at: calmness, readability, trust, narrow side-panel widths.
- Weak at: supervising several concurrent tools or comparing multiple tabs.

### Best for
- Everyday browsing and conversation where the Sidecar should feel present rather than operationally loud.
