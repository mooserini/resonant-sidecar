## Variant: Agent Workbench

### Design stance
Make browser state, capabilities, and live tool execution inspectable without turning them into repeated permission theater.

### Key choices
- Layout: conversation plus a compact activity ledger that collapses below at narrow widths.
- Typography: dense contemporary system UI.
- Color: dark work surface with warm copper structure and semantic status colors.
- Interaction: one-time page-action approval and simulated tool lifecycle.

### Trade-offs
- Strong at: supervising agent work, diagnosing failures, understanding authority.
- Weak at: relaxed long-form conversation; the activity rail competes for narrow space.

### Best for
- Power users who want to see exactly what Hermes is doing while retaining a conversational center.
