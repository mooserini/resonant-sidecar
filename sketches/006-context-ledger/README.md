## Variant: Context Ledger

### Design stance
Treat every page-derived item as an inspectable, removable entry rather than an invisible assistant capability.

### Key choices
- Layout: compact page identity, centered context ledger, composer-attached scope drawer.
- Typography: product body type with terse monospaced state labels.
- Color: dark archival earth tones with green for live state and magenta only for the send action/focus.
- Interaction: text sharing updates both the ledger and composer attachment tray; camera capture is independently visible and removable.

### Trade-offs
- Strong at: inspectability, mixed-context work, and proving exactly what the next message carries.
- Weak at: slightly more tool-like and less emotionally warm than the quiet companion direction.

### Best for
- Power users, research, debugging, and any session where context provenance matters as much as conversation.
